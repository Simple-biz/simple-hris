# Noto Sans — SIL Open Font License 1.1

`noto-sans-regular.ts` and `noto-sans-bold.ts` are base64-encoded **subsets** of
Noto Sans (Regular 400 / Bold 700), generated by
[`scripts/build-pdf-font.mjs`](../../../../scripts/build-pdf-font.mjs) and reduced
to the 200 code points the HRIS PDF exports can draw.
