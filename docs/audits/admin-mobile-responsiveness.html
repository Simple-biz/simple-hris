The common failure

Root cause The two-pane app-shell never let go on mobile

The blocked tabs share one desktop pattern: a fixed-height master/detail shell (h-full + flex-1 + overflow-hidden) pinned to the viewport with its own internal scroll. When it collapsed to a single stacked column on a phone, it stayed pinned — and because the Card primitive always carries overflow-hidden, the roster's scroll region shrank to near-zero height. That's the "scrollbar, but no entries" you saw in the Global Master List.

The fix, applied consistently: keep the pinned shell at lg and up (desktop is unchanged), but let panes flow at natural height on phone/tablet so the page itself scrolls.

// each pinned container, gated to desktop only flex h-full min-h-0 overflow-hidden flex → lg:h-full lg:min-h-0 lg:overflow-hidden
