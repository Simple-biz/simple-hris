# OWASP Top 10:2025 audit — 2026-10-01

> **⚠ DO NOT PUSH this file while `Simple-biz/simple-hris` is public (OW-1).** It is a working exploit list.
> The commit that adds it, and anything after it, should reach `origin` only once the repo is private.

Session `f13767cd`. Kane: *"run OWASP"*. **No code changed.** Every fix below is a `hardening` change, and
none is made here.

**Method.** Five read-only agents, one per category pair (A01 · A07+A04 · A05 · A02+A08 · A09+A10+A06),
each briefed with the open items already on record so it would re-verify them, not re-find them. The A01
agent classified **all 503 exported handlers across 337 route files** by their gate, and read about 150 of
them in body for ownership and department scope. Plus `npm audit` against the lockfile, and `git` / `gh`
reads of what is on `origin/main` and the repo's visibility. Nothing touched Supabase, nothing ran against
production, and nothing was exercised live. **This is a code read, not a pentest.**

**Verification key.** **V** = re-read in the code by this session after the agent reported it. **M** = measured
here (`npm audit`, `git ls-tree origin/main`, `gh api`). **A** = an agent's code read with file:line, not
re-read by this session. Treat **A** rows as strong leads, and re-read the line before fixing.

**Threat model.** `proxy.ts` requires a NextAuth JWT for every `/api/*` except auth, onboarding,
bank-update, gift-address, secret-bearing cron and keyed external calls. So the realistic attacker is
**any signed-in `@simple.biz` account, a roleless employee included**. That audience is about to become
the whole company. Rows marked *public* need no sign-in at all.

---

## Do first

1. **Make `github.com/Simple-biz/simple-hris` private.** It is **PUBLIC** (OW-1), and `origin/main` carries
   production bank account numbers. Then purge the files from history and rotate everything committed.
   Treat the data as exposed. This needs a Data Privacy Act breach assessment, because the NPC
   notification clock is **72 h from discovery**. Kane's call, and only Kane pushes.
2. **Shut the impersonation backdoor in production** (OW-4). Its default password is now on a public repo.
   Set `SUPER_ADMIN_IMPERSONATION=off` in Vercel and rotate `NEXTAUTH_SECRET`.
3. **Gate the four bank-data leaks reachable by any signed-in employee** (OW-2, OW-7, OW-12, OW-13),
   before the all-employee release.
4. **Cobrowse** (OW-3): the person being watched must refuse unverified watch requests. A kill switch on
   the app-wide driver is the stopgap.
5. **Upgrade `next` to ≥ 16.3.6** (OW-5) and `next-auth` to ≥ 4.24.15 (OW-40).
6. **Escape or validate emails on the five wildcard write routes** (OW-9).
7. **Rotate the n8n webhook URLs** (OW-20). They are public now. Add a shared secret.
