# Meeting Discussion: HRIS System Integration and KPI Workflow Optimization

**Date:** June 9, 2026  
**Participants:** Kane R, Jackie Z

-----

## Executive Summary

This meeting focused on reviewing the newly implemented HRIS system features, specifically regarding onboarding and offboarding procedures for the Legion department. Additionally, the participants evaluated the Manager Dashboard and the existing KPI calculation workflow to identify opportunities for automation and efficiency improvements.

## 1\. HRIS Onboarding & Offboarding Review

Kane provided a detailed walkthrough of the updated HRIS features intended to streamline personnel management.

  * **Onboarding:** The system now supports bulk processing for Legion, allowing for the generation of multiple onboarding paperwork links simultaneously. This feature aims to replace manual, individual processing for the department.
  * **Offboarding:** Kane demonstrated three distinct automated options for offboarding:
      * **Offboard:** Triggers automations across Hubstaff, Roboform, and the clinical Gmail workspace.
      * **Deactivate:** Suspends account access with the ability to restore, rather than permanently deleting data.
      * **Delete:** A more permanent action that removes the profile from the HRIS and revokes workspace access.
  * **Current Operational Status:** Jackie noted that they will continue using the existing email-based offboarding process for the time being, as it currently loops in necessary stakeholders (Bob and Karen) and aligns with the team's current familiarity with the process.

## 2\. Manager Dashboard and KPI Calculator

The discussion highlighted the current manual inefficiencies in the KPI calculation process and outlined necessary upgrades.

  * **Workflow Assessment:** Jackie explained that the current process involves manual sorting and copying/pasting appointment data from a scoreboard sheet to a tracker. This process is labor-intensive and relies on "Scorecard Names" as the primary identifier, which Jackie identified as redundant and prone to inconsistency.
  * **Strategic Optimization:**
      * **Single Source of Truth:** Kane proposed transitioning to using the employee's work email as the unique identifier across all systems to improve data integrity and eliminate duplicates.
      * **Dashboard Integration:** Kane will integrate the scorecard directly into the Manager Dashboard for the Legion department, allowing employees to access their KPIs directly through the system.
  * **Requested Enhancements:** Jackie requested the following features for the updated dashboard:
      * A functional search bar to facilitate easier navigation of the 280+ employees.
      * A view that includes both Full Name and Work Email.
      * Sorting capabilities that allow alphabetical arrangement by either Full Name or Work Email.
