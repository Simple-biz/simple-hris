CallTools batch tester — oriented hires

Fires the exact call_tools_creation payload HRIS sends on mark-attended, once per pasted person. Built for verifying / backfilling a batch (e.g. the last 79 Lead Gen hires just marked as oriented).

Point at the production URL (…/webhook/…, workflow active) for a real batch — an n8n test URL (…/webhook-test/…) captures only the FIRST event. You can also point it at a dedicated verify webhook.

Batch defaults

Applied to any row that doesn't set the field itself. A row's own value always wins.

pay_rate mirrors regular_rate (0 when unset), matching HRIS. Leave rates blank if your flow doesn't need them for verification.

Where do I get the list of oriented people?

Run this in the Supabase SQL editor, then copy the single JSON cell it returns and paste it below. It grabs the most-recent oriented hires and joins their onboarding submission for the minted CallTools fields.
